# 随钻测井方向：可选检查

仅当本轮需求选择采样、压缩、低速回传或上位机分析时使用。先固定输入样本格式、通道数、采样时序、误差上限、帧格式、链路速率和评估数据集，再决定 RTL 与外设。选题初稿中的 AD7606、RS485/电力线、差分/RLE/字典压缩、Ryzen AI、数字孪生均是候选，不表示已有接口、芯片或指标获批。

- **采样链路**：若采用 AD7606 等采样器，核对实际模块原理图、逻辑电平、时序、采样 epoch 和通道顺序。通过仿真及采集记录检查丢样、重复、通道错位和配置切换；配置应在协议允许的安全边界生效。
- **缓冲与跨域**：源端突发、下游停顿和链路断开时，检查 FIFO 满空、溢出/背压、恢复后的样本顺序。跨时钟和复位释放按所选 FIFO IP 契约验证；单侧复位必须定义为可测试行为或明确禁止。
- **协议**：为版本、长度、序号和 CRC 确定唯一编码/校验定义。黄金模型覆盖 CRC 错误拒收、序号间隙、错版本/长度后的重新同步、复位与断链恢复。
- **低速回传**：若采用 300 bps 的 UART 8N1，单纯串行负载上界是 `300 / 10 = 30 byte/s`，还未扣除帧头、CRC、重传与空闲。分别计算平均、最坏与突发队列需求；区分本地原始采样流和低速趋势/摘要上行。
- **压缩与效果**：在固定输入集上用独立解码器校验可逆性，或先批准有损误差界。记录压缩率定义、端到端延迟、吞吐、异常数据退化，以及每次构建的 LUT/FF/BRAM/DSP 和关键路径。4:1～8:1、微秒级或固定降精度都不是默认验收线。

同一激励和判定规则应尽量复用到 RTL 仿真、硬件在环和板测；每层单独标记实际是否执行。PC/Ryzen AI 处理若后来加入，记录它与 FPGA 测量的接口和各自延迟，避免把上位机结果当作 FPGA 板上证明。
