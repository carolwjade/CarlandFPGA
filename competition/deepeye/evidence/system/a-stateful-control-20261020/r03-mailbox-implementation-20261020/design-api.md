# Bounded latest-completed mailbox: selected implementation contract

Main selected the small mailbox integration design in assignment.md. This note resolves its API before code. It is not a new public ABI or activation approval. H01–H15 remain unchanged; all29/R03 remain not_run.

`LatestCompletedMailbox(profile_document)` freezes the actual software BOOT document. `activate(context_raw, generation, slot_origin_ns, source, clock_domain, bounds, now_ns)` validates the existing sealed context and full document digest. Context uses existing topology1 HIL/topology2 PC_DIRECT and transport profile1/2. Each activation requires a never-used session and increasing generation; any attempted replacement stops the old activation first. Retain at most64 session identities, then refuse further activation. STOP is irreversible for that activation. Restart needs a fresh session, not a new epoch under the old session. Actual global/process-restart session freshness remains the authenticated BOOT provider's obligation.

`TransferBounds(usb_upper_ns, packing_upper_ns)` supplies explicit strict nonnegative integer costs. `None` means unknown. `source` and `clock_domain` are retained original verifier identities, compared by identity; None means unknown. They are not credentials, authentication or measured bounds. The caller must provide independently verified records and causal completion association. This library has no provider/default that can establish those facts or enable motion.

`observe(raw, sample_lower_ns, now_ns)` validates existing TELEM/EVENT envelopes and CRC/context. Retain at most four immutable original raw records and conservative sample lower bounds; unknown mapping stays non-consumable. Observation sequence strictly advances within the session, except byte-identical retained repeats, which do nothing. Backward/half-range/ambiguous sequence transitions stop. Sample time is never replaced with receipt/completion time; mapped/native timing cannot be younger than the supplied lower bound. Eviction prevents future consumption of that reference.

`Completion(generation, source, clock_domain, candidate_raw, invocation_id, dispatch_lower_ns, completion_lower_ns, completion_upper_ns, deadline_ns)` retains the original verified association as immutable bytes/scalars. `complete(record, now_ns)` validates the existing model_candidate schema, exact BOOT context/model observation, causal timeline and bounds. Ordering is original observed-seq first, then strictly increasing candidate_id AND invocation_id, consistent with existing actor progress association. A later-arriving completion for an older original observation is dropped, even if its completion timestamp is later. Exact repeats are no-ops; conflicting identities stop. One pending usable completion plus its last accepted high-water/fingerprint is bounded and retained after consumption. No set of unbounded retired candidate keys is kept; lower identities cannot return. Invalid/conflicting inputs stop instead of rejuvenating state.

`SlotGrant(generation, window_index)` identifies one caller-verified decision slot; None is unknown. `plan(now_ns, grant=...)` returns immutable `Selection` or None. It uses `boot_profile.late_candidate_action` with ready=max(original completion upper+USB+packing, now), relative to the fixed slot origin. It additionally enforces actual selected start strictly below BOTH original completion deadline and original sample lower+FAST1500ms/STRESS12000ms, including the helper's early-ready branch. A mismatched/absent grant, unknown context/bounds, expired/evicted observation or already consumed slot produces no selection.

`consume(now_ns, grant=...)` consumes only if now equals that selected legal slot start; early calls plan but do not consume, late calls defer. It returns the original candidate bytes/times/context and selected mode/window/start/deadline; it creates no command, HIL capture, heartbeat or motion grant. PC_DIRECT uses the same profile decision epochs for software candidate arbitration only; it emits no fictitious downlink bytes. HIL/PC_DIRECT actual transport authority remains outside this library.

Every time-taking call advances a strict nonregressing integer host-time high-water. The owner serializes calls; no callbacks/threads/processes/models/hardware are started. `snapshot()` returns a detached bounded diagnostic view, not authority. Invalid public input latches STOP and raises ValueError; normal missing/early/late/unavailable cases return None/False as documented.
