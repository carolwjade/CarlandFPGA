# Original source to TRACE scan bytes

`functional50_exchange_a.load_selected(snapshot_root)` loads the fixed B131 bundle once. After the original `FunctionalSource.start()` and before its first sample, construct `OriginalSourceTraceScan(functional_source, bundle)`. It requires the exact original source, schema 3 Book and QPC binding, with no earlier samples. Every time `poll_sample()` returns a payload, call `producer.admit(payload)` immediately in original order, then `functional_source.release_sample(payload)`. One SourceLedger starts at tick 0 and the original QPC origin; it accepts the complete observed history, including initial invalid/C3-null records. Skipping records, stale receiver timing, changed Book/source identity, or failed admission latches the producer and is not replayed.

Select an already admitted original payload object and call `producer.prepare(payload, facts=..., build_binding=...)` once. `facts` must have exactly `work_id`, `declared_by`, `scan_id_uint63`, `view`, `frame_seq_start`, `sample_index`, `binding_receipt_id`, and `lineage`. The lineage must have B113's exact `operation_id`, `request_id`, `request_hash`, `tested_commit`, `build_id_hex128`, `boot_id`, numeric `session_id`, `tag`, `trigger_id`, `generation`, `request_seq`, and `capture_seq`. The build binding is the four-field B131 `canonical_build_id_full_sha256`, `source_closure_file_sha256`, `operation_id`, `request_hash`. These values must come from the actual Root/physical callsite; the producer does not infer an equivalence between separate BOOT contexts, authenticate them, or acquire a board.

The result is the original fixed B131 `Preparation`: its `original` retains the request bytes, original payload bytes and all four companion byte strings. B113/B131 applies its own caps, four ordered nonwrapping frames, declared association and representability checks. If a B131 refusal occurs, the consumed producer retains `_attempt` and `_result` for original-byte evidence; there is no automatic retry or second frozen scan.

Counts remain original 0..4095 or null, without scaling. `candidate_four_channel_quality_v1` uses the existing `pack_candidate_quality` mapping; full original quality remains opaque in each lane. The B113 common acquisition time is the **nominal ADC grid time** `origin + adc_tick_ms * 1e6`; valid EM source times use the original EM tick and the valid ADC lane uses the original ADC tick. These are not claimed as exact measured acquisition instants. Each Root-private companion carries complete original payload bytes, full original Book draft including actual ADC/EM call and held-scope brackets, original QPC metadata, the complete time/quality/context records and lane identity. Association hashes identify those exact record bytes and are not credentials. Companions can contain Root-private numerical pose information and must remain within authorized Root evidence handling.

The new controls use synthetic data only and verify early invalid lanes, C4 history, held EM, exact original-byte retention, B113/B131 acceptance, nonwrapping frames, changed payload refusal and missing-history refusal. They do not prove native Root sampling, freshness at physical consumption, BOOT, board state, inference, G03 or H12; neither this producer nor B131 authorizes MMIO.
