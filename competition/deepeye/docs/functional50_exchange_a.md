# B131 → original A TRACE session (candidate)

`load_selected(snapshot_root)` reads pinned, unchanged B131 modules from `competition/deepeye/tools/diagnostic/functional50_adapter128/` and verifies the exact input113 and codec dependency paths/hashes before loading their original bare imports. It refuses pre-existing names `dependencies128`, `adapter128` or `reducer128` instead of adopting them, and does not alter sys.path or vendor source. Use a Root-owned frozen source snapshot; byte hashes by themselves do not authenticate a build or protect against a concurrent writer between hash and import.

Root must separately select and verify the actual same-run qualified BIT/HWH/build closure, original source, input/companion semantics, and same-boot device/operation identities; keep the original A SSH session and its outer Job. This module does not authorize a load or operation and carries no G05 access. The `build_binding` is the exact B131 four-key mapping; its operation_id must equal the original SSH session operation directory. The exact request/source/four companion bytes are durably created before scan; B131 retains their original semantics as opaque and does not establish current eligibility.

`Exchange(bundle, session, original_qpc, request_bytes, source_bytes, companions, build_binding=..., timeout_ns=...)` runs B131 prepare and creates the one-use local `b131-exchange` directory. A refused preparation is preserved but cannot scan. `scan()` runs the original reducer's `begin/advance`, one TRACE intent at a time, through that exact A `Session.request`. Each intent has a 2048-byte file written before the call, with its result placed in its second half; original Session also records its own request and full raw response. A checks its actual per-phase evidence sizes with conservative next-call headroom before effect. Limits are finite; no rearm/second scan is allowed.

`collect()` calls `begin_collect` once after B131's actual successful/quiet state, retains raw confirmed prefix and reducer snapshot and calls the actual `correlate_collected` with four original complete companions and actual result rows. Its output is wire/companion consistency only. `cleanup()` is a separate one-use request through `begin_cleanup`; the reducer only permits it after an attempted original ARM, no pending operation, and a healthy usable session. The caller selects if and when cleanup is appropriate. No automatic second call occurs on unknown or error. A transport exception is conservatively reported to B131 as unknown; the session is not replayed, and the original process plus board state remain Root's responsibility. A failure during local intent reservation is not attempted; failed persistence after an effect leaves no usable continuation.

All host QPC values bracket host protocol observations, not remote MMIO execution intervals. SSH timeout or local termination cannot prove device stopped. Existing A port enforces one ARM and 5000 I/O; B131's larger logical POP ceiling cannot expand that limit, so unusually large failure FIFO may remain only partially collected. Six controls ran only in software, including a synthetic actual-B131-to-original-Session boundary control. That control temporarily bypasses the compatibility preflight to exercise the first identity read; it does not modify the port or prove complete operation. At that earlier control the real preflight refused because the board port omitted RX-total read offset 0x034. A184 subsequently added the read-only offset; Root must independently review and release the compatible port before execution. They do not qualify any live board, source, clock, H12 or acceptance gate. Out-of-band delayed SSH stdout and remote-file verification remain separate open boundaries of the underlying session.
