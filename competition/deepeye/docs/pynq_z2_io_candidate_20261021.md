# PYNQ-Z2 package and electrical integration candidate

See the [reviewed R02 candidate](../evidence/system/a-r02-io-map-20261021/README.md).
Fifteen package pins, four ADC channels and three external PWM/capture pairs
are documented for the future custom top. The J3 I2C contact numbers conflict
in primary sources and must be resolved on the actual PCB before wiring.
No physical, bitstream or full R02/R03 acceptance is claimed.
