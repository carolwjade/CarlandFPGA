# TRACE batch protocol v1

This is an explicit, one-shot alternative to the existing scalar CSR session. It grants no authority and performs no board action merely by importing these modules. The existing scalar `SessionSpec` and 13-key board plan retain their defaults. Only A/Root may later select a qualified operation and operate the board.

Root first finishes and independently reviews the selected board entry and B131 files in a fixed snapshot tree. `functional50_board_trace_batch_a.make_manifest_bytes(absolute_snapshot_root)` returns a canonical manifest containing exactly eight fixed paths: the batch entry, original `functional50_board_a.py`, the pure B131 loader, the three unchanged B131 modules, original B113 normalizer, and original codec. Root must save, upload and read back those exact source files and a file named `trace-batch-manifest.json`, recording the SHA-256 of the complete manifest. The manifest binds bytes for this operation; it does not authenticate the peer, board, build, or BOOT. The server verifies the manifest digest and every fixed file before importing the original board module or opening PYNQ.

Set the trailing `SessionSpec` fields `protocol='trace_batch_v1'`, `remote_manifest='<absolute path>/trace-batch-manifest.json'`, and `remote_manifest_sha256='<64 lowercase hex>'`; `remote_script` must be the fixed `functional50_board_trace_batch_a.py` path in the same uploaded snapshot tree. The remote command remains the same pinned board Python with `-I -B`, plus the plan and manifest arguments. `open_session` keeps the original SSH process, waits for real server readiness after manifest/B131/PYNQ/load, and records the manifest selection. The scalar `request()` is refused on a batch session.

Create `BatchSession(original_session, fixed_bundle, original_qpc)` and call `exchange(id, b131_preparation, build_binding=..., timeout_ns=...)` once. It revalidates the complete B113/B131 original bytes and preserves the request, source and all four companions before sending one canonical JSON line. Exact envelope keys are `schema`, `id`, `operation_id`, `request_hex`, `source_hex`, `companions_hex`, and `build_binding`; total decoded originals are at most 2 MiB and individual B113 bounds apply. No offset, callback, code or arbitrary CSR operation can be supplied. Host started/returned records bracket the actual complete request/response with the original QPC; they do not establish remote computation or physical source time.

The board retains the full original bodies and binding inside the existing original operation directory. It runs the fixed B131 Reducer against the same exact `_TracePort`, preserving original per-CSR started/returned records, its existing 5000-call limit, ARM/lane/CANCEL quotas and reducer evidence and work/cleanup limits. Work and cleanup elapsed times are board `monotonic_ns` differences, not host QPC values. It attempts no effect after an unknown CSR outcome. A hanging MMIO call cannot be interrupted by these logical budgets; an SSH timeout means the original effect may remain unknown and must not be replayed.

The response is one bounded line of at most 4096 bytes with schema/id/operation, actual B113 request SHA, declared lineage request hash, status, original wire hex or null, `wire_complete`, original result rows, total original port IO count, batch IO count, explicit `cleanup_observed`, terminal observation and unknown flag. `QUIESCENT` requires this run's owned CANCEL to complete with its own quiescence observation; an earlier preflight observation is insufficient. Partial wire is never presented as complete; oversized prefixes remain in the original board evidence directory. On `COMPLETE`, the host passes the returned original wire and its separately retained four companions through the fixed B131 correlation. Correlation is byte consistency, not BOOT, sensor authentication, board acceptance, source freshness or motion approval.

New software-only controls cover envelope and manifest bounds, scalar versus explicit batch selection, a full original B131 reducer scan/collect/owned-CANCEL with a synthetic port, original frame correlation, one-shot host/QPC bracketing, and an unknown synthetic CSR effect. They are not physical board or performance evidence. No SSH, PYNQ, hardware, Godot, PDE or AI model was invoked by these controls.
