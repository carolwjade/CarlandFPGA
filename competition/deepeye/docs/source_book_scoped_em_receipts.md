# Opt-in original scoped EM call observations

The new plan profile `root_original_source_time_book_em_receipts_v2` requires `root_original_em_scope_v1`. It creates a source book with `scoped_em_receipts=True` and evidence schema2. The default v1 book keeps its previous schema and unavailable association. This changes source observations only; it grants no motion, BOOT, channel, calibration or board authority. The completed source70 run remains unchanged schema1 historical evidence.

The fixed original source pump takes the actual EM pose read, opens a one-use book call handle before the original acquisition/JIT invocation, records its return while the exact scope is active, and retains the receipt only after the same scope has actually exited cleanly. End and close attempts are consumed once. Original profile tick/attempt/success/value/saturation progression, exact scope/factory/owner/thread/Root associations and QPC order must match. A previously consumed EM tick, failed scope, changed Root, mismatched handle or relabelled payload fails closed. A failed EM attempt remains unavailable.

Each successful receipt retains the original source origin/count/tick, original pose read, actual call bracket, observed scope-close QPC, numerical pose span, Root/pose/revoke revisions and observed EM values/saturation. Later held records refer to that original receipt. A later fresh acquisition replaces the live reference while earlier sample records retain theirs. This is an observation of a call made under numerical Root custody. It is not a physical EM measurement, atomic native transform interval, native GPU trajectory, board capture/admission identity or action completion proof. C30/C31 integration still requires the separately specified genuine evidence and agreed projection semantics.

New controls use distinct software owner/factory/book seams and do not execute the original sensor kernel, PDE, Godot or board. The first missing-feature RED is preserved.
