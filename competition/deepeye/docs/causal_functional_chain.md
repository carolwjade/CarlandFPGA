# Causal functional source orchestration

`acquire_functional_world(spec, policy, initial_standoff_m, operation_id=..., output_dir=..., field_policy=..., jit_runtime=..., clock=...)` acquires a new original production owner using the exact `ApprovedLaunchSpec`, its original QPC binding and the matching `ValuePolicy`. It requires a new absolute output directory holding the two fresh native logs and records the operation and original snapshot there. It polls the original HELLO, freezes with the original limits and policy digests, constructs and binds the actual epoch, and waits for the original INITIAL_VIEW APPLIED and finite getter readback. The getter differences are preserved, not reinterpreted as zero error. It returns a `FunctionalWorld` with the prepared source. The original native containment and initial-view deadlines are never extended while awaiting external readiness.

Use `world.source.start()` only after the real board and AI are ready; then use the calls below. On exit, `world.close(reason)` uses original composition, source and owner cleanup and retains actual status, resources, close history and errors; cleanup alone is not evidence of behavioral STOP. `FunctionalBootstrapError` retains the cause and lifecycle for failed acquisition. An unknown release is recorded without replay.

`FunctionalSource` accepts only Root's original retained initialized world owner, its existing binding, explicit field policy, and optionally the already verified and warmed original JIT runtime. It constructs the original field, source and scoped EM factory; optionally binds the fixed JIT backend; then creates `RootWorldService`, the owner's original actor link and schema 3 actor source Book, opts into completed-token custody, prepares the source without starting it, and attaches the original projection session. After external readiness, call `source.start()` once; source session timing begins then. It does not acquire a native world, choose a scene, fabricate an admission, or substitute a clock.

The Root caller owns the original native world startup and cleanup and the real production channels. `activate_original_authority(config)` uses the existing fixed original-world factory once. If genuine production channels are unavailable, that factory rejects; no retry is attempted. Root and C46 must supply real board/admission/capture/registry records and the fixed invocation path. `required_external_bindings()` is an explicit unavailable marker, not a provider.

At actual callsites, attach the original configuration and admission via `observe_config` and `observe_admission`. `poll_sample()` returns the real payload and original completed token or `None`; call `release_sample(payload)` promptly to free the single source slot while retaining the exact original payload and token. Later pass that same unchanged object to `capture` with the actual capture reference, candidate and fields. Each retained sample can be captured once; capturing the currently held sample also releases it. A failed capture leaves the held slot intact. At most 1001 records are retained; no sample is dropped. Released, uncaptured samples remain bound to their original Book and time across a transition. Attach real registry view and observation with `attach_registry`, and use `read_current`/`export` for the underlying projection. Root owns actual observation and actor actions. Once an original transition has completed, attach it with its actual successor, slot and fields using `observe_finished_transition`; no further source poll is accepted until the newest transition is attached, and the first poll after it uses the original origin-relative 10 ms not-before gate. Polling never backfills or refreshes stale EM data.

All objects and callsites remain trusted-process custody, not a security boundary. Mutable payload byte snapshots cannot detect a modification that is later restored before checking. The new controls exercise software call order and rejection only; they do not demonstrate a live Root, real BOOT, board I/O, CPU inference, motion, G03 or H12. Actual integration requires independent review and a separately authorized live operation.
