# Original Root projection callsite

`source_projection_v1` vendors the exact C42 assembler and C36 request schema; it does not alter the four pinned original modules. Construct `ProjectionSession.attach_original(owner, link, book)` only from the retained original Root thread after original actor/source custody is ready. The underlying C42 factory performs exact type, source hash, binding and custody checks.

At actual Root callsites call `observe_config`, `observe_admission`, `observe_capture` with the original completed token, and `observe_finished_transition` only after original transition closure and, for STEP, a returned known committed slot. The session retains references, creates opaque UUID labels only for present objects and never dispatches, obtains BOOT or grants completion. Caller-supplied external fields and `bind_observed` are trusted callsite attachments, not independently authenticated by the label. Keep the entire original source prefix and capture/action history; bounds are imposed by unchanged C42 and no history is silently trimmed.

Call `read_current()` once per actual requested read and retain its returned object. `attach_registry` requires an explicit original view, separately retained observation/hold receipt and explicitly supplied observed as-of time; it never copies the getter timestamp into the registry. The session cannot authenticate arbitrary external receipt contents or prove a view was stable over the getter bracket. The Root orchestrator must establish that original observation and C36 must validate it; if unavailable omit registry and export stays partial. No synthetic happy path or fake time should be provided. The exact C42 `partial`, `missing_paths`, `dropped_paths` and `proof=None` behavior remains; `ASSEMBLED_UNVALIDATED` is not authenticated source or execution permission.

No production orchestrator invokes this component yet. Board capture, config, source admission, registry observation/hold and actual actor transitions must be supplied by the real original callsites; none are manufactured here. No C36/C28 dispatch, BOOT, movement or H12/board acceptance is provided.
